# PLATE プライバシーポリシー（ドラフト）


最終更新日：2026年10月6日
事業者：宮澤知輝　連絡先：tomozawa1997@gmail.com

PLATE（以下「本アプリ」）は、トレーニングと食事の記録から、1日の食事の目安（カロリー・たんぱく質・脂質・炭水化物）を提案するアプリです。本アプリで扱う情報と、その使い方を説明します。

## 1. 取得する情報
| 情報 | 内容 | 保存先 |
|---|---|---|
| 記録 | 体重、食事、トレーニング、プロフィール（身長・年齢・目標など）、食事の写真 | **この端末の中**（ログインしなくても使えます） |
| ヘルスケアのデータ | 体重・体脂肪率（**読み込みのみ**。書き込みはしません。許可した場合のみ） | この端末の中 |
| アカウント情報 | メールアドレス、ログイン方法（Apple）、ユーザーID | 認証サービス（Supabase） |
| バックアップ | ログインした場合に、記録の全体と、食事の写真 | クラウド（Supabase。写真は非公開の保管領域で、本人だけが読み書きできます） |
| AI推定に送る内容 | 食事の写真・文章（ひとこと） | 推定のため、AI処理の事業者へ一時的に送信 |
| クラッシュ情報 | アプリが落ちたとき・エラーが起きたときの、エラーの種類、どのコードで起きたか、アプリのバージョン、OS・端末の機種。**食事・体重・プロフィールなどの記録、ユーザーID、メールアドレス、写真は含みません** | 不具合の調査のため、クラッシュ監視の事業者（Sentry）へ送信 |
| 使われ方の計測（任意） | 設定で**自分でオンにした場合だけ**。端末ごとのランダムなID、起動したこと、食事を記録した日付と入力方法の種類（検索・文章・写真など）、無料体験を始めたこと、購入したこと（購入した商品の種類）、トレーニングを初めて完了するまでの日数。**食事の内容、体重、プロフィール、写真、メールアドレス、ユーザーIDは含みません**。IDはアカウントとは結び付けません | 使われ方の集計のため、Supabase へ送信。オフにすればそれ以降は送らず、端末のIDも消えます |
| 購入情報 | 有料の機能を提供する場合に、購入状態（現在は有料の機能はありません） | 決済管理（RevenueCat / Apple） |
| コーチとの共有（任意） | 「コーチと共有」を**自分で承認した場合だけ**、自分が選んだ項目（食事・体重・トレーニング）の直近約2か月分。コーチが送った目標・メニュー・ひとこと | クラウド（Supabase）。共有相手のコーチだけが読めます |
| コーチとして使う場合（任意） | コーチ名、招待コード、生徒の名前（生徒が入力したもの）と共有された記録、作ったメニュー、送った目標とひとこと | クラウド（Supabase） |

広告のための情報、位置情報、連絡先は取得しません。

## 1-2. コーチとの共有について（任意の機能）
本アプリには、トレーナー（コーチ）に記録を見てもらい、目標やメニューを受け取れる機能があります。**使わない場合、何も共有されません。**
- 共有は、招待コードを入れて**利用者本人が承認したときに始まります**。承認するまで、コーチには何も見えません。
- 見せる項目（食事・体重・トレーニング）は、項目ごとにオン／オフできます。オフにした項目は、コーチには「非公開」とだけ表示されます。
- **写真、メモ、生年月日などのプロフィールは、共有しません。**
- 共有はいつでもやめられます（設定 → コーチ → 共有をやめる）。やめると、コーチからは見えなくなり、コーチ側に置いた共有データも削除されます。「ひとりで」に切り替えると、共有を一時停止できます。
- コーチが目標・ペース・たんぱく質・メニューを決めると、その内容が自分の設定に反映されます。共有をやめるか「ひとりで」に切り替えると、最後の内容を自分の目標として引き継ぎ、自分で変えられるようになります。
- コーチは、本アプリの利用者の1人です。コーチが受け取った情報の取り扱いは、コーチ自身の責任で行われます。当方は、コーチの助言や指導の内容を保証しません。
- アカウントを削除すると、コーチとのつながりと共有データもすべて削除されます。

## 2. 利用目的
- 記録の表示、目標の計算、レビューの表示
- ログインと、バックアップ・復元
- 食事の写真・文章から、食べたものと量を推定すること（利用者が確認して修正してから記録されます）
- 有料プランの提供と、その状態の確認
- 「コーチと共有」を選んだ場合に、選んだ項目をコーチに表示すること、コーチが送った目標・メニュー・ひとことを届けること
- 不具合の調査と、サービスの改善（個人を特定しない範囲）
- 「使われ方の計測」をオンにした場合に、使い続けている人の割合などを集計すること

## 3. 第三者への提供・委託
本アプリは、次の事業者にサービスの提供のため情報の処理を委託します。目的以外には使いません。
- Supabase（認証・バックアップの保管、任意の「使われ方の計測」の保管）
- Google（Gemini API。食事の写真・文章のAI推定。**推定の処理のみ**に使います。外部サービスでの取り扱いは、Google の規約に従います）
- RevenueCat、Apple（購読の管理・決済）
- Sentry（クラッシュ・不具合の調査。送るのは上記「クラッシュ情報」のみで、記録やユーザーを特定する情報は送りません）

法令に基づく場合を除き、上記以外の第三者に個人情報を提供しません。

## 4. 保存期間と削除
- 計測のデータ：設定で計測をオフにすると、以降は送らず、端末のIDを消します。すでに送った分は、IDつきの個別のイベント（IDは仮のもので、アカウントとは結び付いていません）として、集計のために当面保管します。IDがアカウントと結び付いていないため、特定の方の分だけを探して削除することはできません。
- 端末内の記録：本アプリの「データ → すべての記録を削除」、またはアプリの削除で消えます。
- アカウントとクラウドのバックアップ、コーチとのつながり・共有データ：本アプリの「データ → アカウントを削除」でいつでも削除できます（取り消せません）。共有だけをやめることもできます。
- AI推定に送った写真・文章：推定が終わり次第、当方では保存しません（推定の回数だけを記録します）。

## 5. 安全管理
通信は暗号化されます。ログインの情報は、端末の安全な保管領域に置きます。体重などの健康に関わる情報は、大切な個人情報として扱います。
