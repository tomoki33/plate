## 説明文
```
トレーニングに合わせて、今日食べる量が決まる。

PLATE は、筋トレの記録と、食事のカロリー・PFC（たんぱく質・脂質・炭水化物）の管理を、ひとつにまとめたアプリです。高強度の日は多めに、休みの日は控えめに。1週間のカロリーをトレーニングの予定に合わせて配り分け、毎日の目安を示します。

【今日の目標が、トレーニングで変わる】
・1週間の合計カロリーを、トレの予定に合わせて日ごとに配分
・トレの内容が予定と変わったら、その日から自動で組み替え
・食べすぎ・食べなさすぎた日があっても、残りの日でゆるやかに調整（取り返そうとしすぎません）

【食事の記録は、速く・ラクに】
・写真や文章から、食べたものと量をAIが推定（必ず確認してから記録できます）
・日本食品標準成分表（八訂）にもとづく栄養計算
・いつもの食事をワンタップで入れるマイセット、よく食べる食品のカタログ
・「ざっくり」で入れる目安入力

【トレーニングの記録】
・種目ごとに重さ・回数・セットを記録、前回の値を自動で表示
・推定1RM、ボリュームの推移
・自分のメニューを作って、週の予定に割り当て

【体重と目標】
・体重の7日平均、目標までの見通し、ペースの見直しの提案
・Apple ヘルスケアから体重を読み込み（読み込みのみ）
・目標体重とペースを設定すると、週のカロリーが決まります

【安心して使える】
・ログインなしでも、記録・目標・レビューなど主な機能を使えます（記録は端末に保存）
・Apple でログインすると、写真からのAI推定、バックアップ、機種変更時の復元が使えます
・記録の書き出し（CSV）、アカウントの削除がいつでもできます
・毎日の記録を催促する通知は送りません

【ご注意】
表示する数値はすべて一般的な計算にもとづく目安で、医療的な助言ではありません。持病のある方、妊娠中の方、未成年の方は、医師や管理栄養士にご相談ください。AIの推定は間違うことがあります。内容を確認してからご利用ください。

食品の栄養成分：文部科学省「日本食品標準成分表（八訂）」を加工して作成
```

## 提出までの手順
1. App Store Connect → 「マイ App」→ ＋ →「新規 App」：プラットフォーム iOS、名前 `PLATE`、言語 日本語、Bundle ID `app.plate.pfc`、SKU、ユーザアクセス「フルアクセス」。
2. 「価格および配信状況」では、**配信する国を日本のみ**にする（画面がすべて日本語のため）。上の内容を、「App 情報」「価格および配信状況」「App のプライバシー」「バージョン 1.0」に入力（スクリーンショットもここ）。
3. 本番ビルドを作って提出：
   ```bash
   npx eas-cli build --profile production --platform ios
   npx eas-cli submit --platform ios
   ```
4. App Store Connect のバージョン 1.0 に、上がったビルドを選び、「審査に提出」。
5. 審査（通常 1〜3 日）→ 通ったら「手動でリリース」を押す。
